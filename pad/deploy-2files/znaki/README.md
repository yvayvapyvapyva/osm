# Дорожные знаки

- `catalog.json` — 427 знаков разделов 1–8: код, группа, название, файл, размеры и лицензия.
- `webp/` — изображения до 96 px по большей стороне, прозрачные поля обрезаны.
- Старые `*.svg` и `*.png` в корне оставлены для сцен, сохранённых до появления каталога.
- Источники и лицензии каждого файла указаны в `catalog.json` (Wikimedia Commons).
