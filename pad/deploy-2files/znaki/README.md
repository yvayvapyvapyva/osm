# Дорожные знаки

- `catalog.json` — 430 знаков разделов 1–8: код, группа, название, файл и размеры.
- `sprite.webp` + `sprite.json` — общий атлас знаков и координаты фрагментов.
- `webp/` — исходные отдельные изображения до 96 px (резерв и совместимость).
- Изображения получены из Wikimedia Commons.
