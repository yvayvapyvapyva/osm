# PAD

Приложение для разбора дорожных ситуаций. Бэкенд сцен вынесен в отдельную
Яндекс.Облако функцию и использует базу данных OSM-проекта.

## Бэкенд

- Функция: `pad-osm`
- ID: `d4esfoiand5dinv3mfth`
- URL: https://functions.yandexcloud.net/d4esfoiand5dinv3mfth
- База: `dbosm` (`/ru-central1/b1gtnlal9r2s3rvqadjn/etnjvaftd6eakeq08kqr`)
- Таблица сцен: `scene` (ключ `name`, постоянный уникальный `id`)
- Сервисный аккаунт: `aje0hrd823msk3hqaikt`

Сцены общие: привязки к Telegram-аккаунту и `user_id` нет.
Сцены из прежней базы PAD (`dbnav`) перенесены в `dbosm.scene`.

Ссылки содержат короткий восьмисимвольный ID сцены, который не меняется при
переименовании. Для старых сцен ID создаётся при первом обращении. Совпадения
ID статистически крайне маловероятны; отдельной проверки на совпадение нет.
Ссылки по имени и прежний формат `ownerUserId:sceneName` не поддерживаются.
При обновлении сначала задеплойте бэкенд (`./pad/deploy.sh`): он автоматически
добавит столбец `id` в существующую таблицу при первом запросе.

Функция публичная и не пересекается с функцией `osmn`, которая обслуживает
маршруты навигатора/редактора в таблице `roads`.

## Деплой

Перед деплоем задайте пароль администратора для удаления сцен в окружении
оболочки. Деплой завершится ошибкой, если переменная не задана. Пароль не
хранится в репозитории:

```bash
export SCENE_ADMIN_PASSWORD='задайте-свой-длинный-случайный-пароль'
```

```bash
./pad/deploy.sh
```

Пароль проверяется backend для сохранения, переименования и удаления сцен.
При открытии PAD пароль не запрашивается: интерфейс спрашивает его
непосредственно перед каждой операцией изменения и передаёт в заголовке
`X-Scene-Admin-Password`. После успешной операции пароль сохраняется в
`sessionStorage` текущей вкладки до её закрытия; если backend отклонит пароль,
он удаляется из хранилища. Публичный список сцен и просмотр остаются доступны
без пароля. После изменений фронтенда обновите номер версии `saveState.js`
в `pad.html`.

## Frontend

URL функции задан в `pad/saveState.js` (`API_URL`). При изменении URL или
кода `saveState.js` обновите версию его скрипта в `pad/pad.html`, чтобы сбросить кэш.
Упрощённый просмотрщик сохранённых сцен доступен по адресу `viewer.html`.
В deployment-сборке это самостоятельная страница без iframe: Telegram SDK,
полноэкранный режим и сцены работают в основном окне Mini App. Viewer использует
общие с PAD папки `pic/` и `znaki/`; при коротком нажатии на «Сцены» открывается
список сцен и выбранная запись запускается автоматически. Долгое нажатие на эту
кнопку открывает редактор PAD. Сцену можно открыть напрямую по ссылке
`viewer.html?scene=<8-символьный-ID>`; её сохранённая запись запустится автоматически.

Для подготовки минифицированной сборки из двух HTML-файлов установите Node.js
и Terser, затем из корня репозитория выполните:

```sh
node pad/build-minified.js
```

Папка `pad/deploy-2files/` содержит самостоятельные `pad.html` и `viewer.html`,
а также общие папки `pic/` и `znaki/`. `viewer.html` собирается из приложения
PAD с включённым режимом просмотра сцен. JavaScript минифицирован и встроен в HTML, а
изображения сохраняются отдельными файлами для кэширования браузером.
Папку можно публиковать целиком. MapLibre, Telegram SDK, карта и API остаются
внешними зависимостями. После изменения фронтенда пересоберите папку.
Бэкенд по-прежнему деплоится отдельно через `pad/deploy.sh`.

## Карта

PAD использует MapLibre GL JS — тот же движок, что и навигатор. Базовая
подложка — «Яндекс.Спутник». Тайлы Яндекса отдаются без ключа и
пересчитываются из EPSG:3395 в Web Mercator в `pad/mapEngine.js`.
Максимальный зум — 21. Ключи карт не нужны.
При изменении `pad/mapEngine.js` обновите версию в `pad/pad.html`.
