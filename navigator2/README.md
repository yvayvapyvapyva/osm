# Навигатор — фронтенд (рабочая копия для оптимизации)

Копия клиентской части навигатора из `navigator/` для экспериментов с
производительностью и интерфейсом. Основная версия в `navigator/` при этом не
меняется, пока изменения не проверены здесь.

Бэкенд (Cloud Function `osmn`, YDB `dbosm`, TTS), скрипты деплоя и редактор
маршрутов остались в `navigator/` — в этой папке их нет.

## Состав

```
navigator2/
├── navigator.html          # клиент навигатора
├── instr.html              # инструкция (вшивается в бандл)
├── ico.png                 # исходная иконка 512×512 (не вшивается)
├── assets/
│   ├── favicon-128.png     # оптимизированная иконка для бандла
│   ├── css/navigator.css
│   └── js/
│       ├── map-styles.js   # стили карт
│       ├── menu-module.js  # меню, список маршрутов, API
│       └── tts-client.js   # кэш TTS из бакета + синтез при промахе
├── scripts/
│   └── build-static-deploy.js
└── deploy-2files/
    └── navigator.html      # собранный одностраничный бандл
```

## Карты

Три стиля, ключи не нужны:

| Стиль | Источник | Особенности |
|---|---|---|
| Нижегородская обл. 3D | `storage.yandexcloud.net/nn-map-tiles/nn-omt.pmtiles` | своя сборка planetiler (OpenMapTiles), обрезка по области, PMTiles + HTTP Range; **выбран по умолчанию** |
| Россия 3D (VersaTiles) | `tiles.versatiles.org` | планета, схема Shortbread, 3D по `height`/`min_height` |
| Яндекс.Спутник | `yandexsat://` | растровые тайлы |

Рендер — MapLibre GL JS 4.7.1 (CDN jsdelivr). Шрифты для подписей берутся из
своего бакета (`.../fonts/NotoSansRegular|NotoSansBold/{range}.pbf`), поэтому
кириллица не зависит от зарубежных CDN. Спрайты не используются: подписи
текстовые, без иконок POI.

Атрибуция OpenStreetMap свёрнута в кнопку ⓘ в правом нижнем углу.

## Оформление

Интерфейс по умолчанию светлый: фон `#F4F6FA`, белые карточки с мягкими
тенями, тёмный текст `#121A28`, зелёный акцент `#16A34A`. Скругления
поверхностей — 12–18 px. В «Настройках» есть переключатель «Тёмная тема»:
он меняет палитру оболочки и сохраняется в `localStorage` (`osm_theme_v1`).
Системная настройка не используется, по умолчанию — светлая тема.

Карта на первом этапе остаётся светлой в обеих темах: `--map-bg` намеренно
не переопределяется в `[data-theme="dark"]`. Превью маршрутов при смене темы
перерисовываются с тёмным или светлым фоном.

Цвета, линии, тени и радиусы собраны в семантические CSS-переменные в `:root`
(`--surface`, `--surface-muted`, `--text-muted`, `--line`, `--green`,
`--danger`, `--shadow-card` и т. д.). Тёмная палитра — это переопределение
тех же переменных в блоке `[data-theme="dark"]`, поэтому компонентам не нужны
отдельные тёмные стили. Общие поверхности карточек и кнопок описаны одним
набором селекторов, поэтому новый элемент не нужно стилизовать с нуля.
Полупрозрачных «стеклянных» панелей нет: все поверхности непрозрачные,
`backdrop-filter` не используется.

Стрелка текущего положения — маркер MapLibre с `rotationAlignment: "map"` и
`pitchAlignment: "map"`. Поэтому она лежит в плоскости карты: наклоняется
вместе с наклоном камеры и поворачивается вместе с её bearing. Направление
задаётся через `marker.setRotation(heading)`, а не ручным поворотом SVG.

## Геолокация и курс

`watchPosition` запускается с `enableHighAccuracy`, `maximumAge: 1000` и
`timeout: 20000`. Курс берётся из `coords.heading`, когда он есть и скорость
выше 2 км/ч; иначе считается азимут по перемещению от базовой точки — база
сдвигается только после смещения на 6 м, чтобы шум отдельного фикса не крутил
стрелку. Если `coords.speed` недоступен (частая ситуация в iOS Safari),
скорость оценивается по перемещению и сглаживается.

Фиксы с точностью хуже 150 м не применяются, пока есть свежий точный фикс
(моложе 8 с): иначе стрелка прыгает через дома. Если точного давно нет —
грубый фикс принимается, а пользователь видит подсказку «Слабый сигнал GPS»
не чаще раза в минуту. Ошибки доступа и таймауты геолокации показываются
тостом. Начальный bearing камеры не выставляется, пока курс не определён,
поэтому север (0°) не путается с «курс неизвестен».

## Верхняя навигация

Вверху экрана — плавающие кнопки разделов «Маршруты», «Инструкция» и
«Настройки». «Маршруты» открывает каталог, остальные кнопки — полноэкранные
разделы с собственной шапкой и кнопкой закрытия. Кнопки остаются поверх
разделов, поэтому переключаться между ними можно одним касанием. Повторное
нажатие на активную кнопку закрывает раздел. Активная кнопка подсвечивается,
получает `aria-current`, а состояние синхронизируется через `MutationObserver`
по классу `hidden` у модальных окон. Разметка рассчитана на добавление новых
разделов: достаточно добавить кнопку с `data-tab` и обработать её в блоке
верхней навигации.

Отдельных кнопок «Маршруты» и «Настройки» поверх карты больше нет: их роль
выполняют кнопки верхней навигации.

## Локальный запуск

```sh
cd navigator2
python3 -m http.server 8125
# http://127.0.0.1:8125/navigator.html
```

## Сборка

Нужен Node.js и Terser:

```sh
cd navigator2
node scripts/build-static-deploy.js
```

В `deploy-2files/navigator.html` получается один файл: встроены
минифицированные стили и скрипты, оптимизированная иконка
`assets/favicon-128.png` и инструкция. Внешними остаются только CDN MapLibre,
картографические тайлы и API. Повторно собирайте после правок в исходниках.

Сборка проверяет бюджет бандла: 220 KB raw и 80 KB gzip. Если файл вырос
больше — сборка падает с ошибкой, чтобы «один файл» не растолстел незаметно.
Иконка также ограничена 32 KB.

## API

Адрес функции задан в `assets/js/menu-module.js`:

```js
API_URL_V2: 'https://functions.yandexcloud.net/d4e02ghbv31h6kpf8ddh',
```

Публичные методы без авторизации:

```
GET ?action=list_routes          # список видимых маршрутов {m, name, description}
GET ?action=list_routes&full=1   # то же + data (геометрия)
GET ?action=get&m=<m>            # один маршрут {name, m, data}
```

Навигатор запрашивает `list_routes&full=1` один раз при запуске и держит данные
в памяти до перезагрузки.

Меню маршрутов сохраняет поиск и выбранную папку в `localStorage`. Пути из
названий маршрутов, разделённых `/`, отображаются как вложенные папки:
список показывает только маршруты текущей папки, а переходы назад доступны
через хлебные крошки. Поиск работает по названиям и описаниям по всему каталогу;
в открытой папке его можно ограничить этой папкой и её подпапками. Карточки
показывают число точек и примерную длину маршрута. Превью показывают полную
геометрию линий и маркеры всех точек маршрута.

Ссылка на маршрут: `navigator.html#m=<m>`.

## Что проверять при оптимизациях

- первый экран: 3D-карта + маршруты (сеть, TTFB, LCP);
- переключение на 3D: время до первого кадра с домами;
- повторный заход (кэш тайлов и шрифтов);
- мобильный интернет РФ: доступность `tiles.versatiles.org`.

После проверки изменения переносятся в `navigator/` и собираются там тем же
скриптом.
