# Navigator Offline

Офлайн-версия навигатора Автоинструктора. Работает без авторизации, без API Gateway и без YDB. Все маршруты и структура папок находятся в одном файле.

## Содержимое

- `navigator.html` — основная страница
- `routes_all.json` — единый файл со всеми папками и маршрутами (включая геометрию)
- `assets/` — CSS, JS, карты, иконки
- `instr.html` — инструкция

## Как запустить

**Вариант 1. Локально через браузер (рекомендуется)**
1. Скопируй всю папку `navigator_offline` на устройство
2. Открой `navigator.html` в браузере напрямую или через локальный HTTP-сервер

**Вариант 2. На веб-хостинге/объектном хранилище**
Достаточно загрузить всю папку целиком. Файл `routes_all.json` должен лежать в корне.

## Озвучка

Озвучка команд и комментариев берётся из `https://storage.yandexcloud.net/eia-tts/` — как и в основной версии. Для работы озвучки требуется подключение к интернету.

## Карты

Используются локальные `maplibre-gl.js`, `pmtiles.js`. Тайлы и шрифты загружаются из публичного бакета `nn-map-tiles` в Yandex Object Storage.

## Авторизация

В офлайн-версии отключена. Покупка доступа и вход через Яндекс не работают.
