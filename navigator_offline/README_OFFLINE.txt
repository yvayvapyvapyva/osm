Офлайн-версия навигатора

Порядок работы:
1. Скопируй всю папку navigator_offline на устройство.
2. Создай файл routes.json в корне этой папки со структурой:
   {
     "folders": [{"folder_id": "...", "parent_id": "", "name": "...", ...}],
     "routes": [{"m": "...", "folder_id": "...", "name": "...", "title": "...", "description": "...", ...}],
     "user": null
   }
3. Для каждого маршрута создай route_<m>.json с содержимым вида {"m": "...", "data": [[...],[...],...]} или просто массивом точек.
4. Открой navigator.html в браузере (или через локальный сервер).

Озвучка берётся из https://storage.yandexcloud.net/eia-tts как в основной версии.
