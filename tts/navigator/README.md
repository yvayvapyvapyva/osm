# TTS: озвучка команд и комментариев

Аудио хранится в Object Storage `eia-tts`, манифест — `v1/manifest.json`.
Ключ объекта — SHA-256 от `текст\0голос\0pitch\0volume`:

- команды: `ru-RU-DmitryNeural`, pitch `-10Hz`;
- комментарии: `ru-RU-SvetlanaNeural`, pitch `+0Hz`;
- volume `+30%`.

Клиенты (`navigatortg`, `navigatortg2`, `navigator3`) вычисляют URL сами,
поэтому ключ в манифесте должен совпадать с этим алгоритмом.

## Полная синхронизация

```bash
cd tts/navigator
python3 sync_all.py           # только отчёт
python3 sync_all.py --apply   # синтез недостающего, чистка манифеста и бакета
```

`sync_all.py`:

1. читает все `cmd`/`comm` из маршрутов `navigatortg` (D1 `nav-db` через
   `wrangler`) и `navigator3` (YDB, таблица `roads`);
2. добавляет служебные фразы навигатора («Сильный удар», «Превышение скорости»,
   «Превышена максимальная скорость») и fallback `Т<номер>` для точек без
   `cmd`/`comm`;
3. синтезирует недостающие mp3 через TTS-функцию;
4. пересобирает `v1/manifest.json` ровно по нужным фразам (правит повреждённые
   записи, убирает лишние);
5. удаляет из бакета mp3, которых нет среди нужных фраз.

Перед изменениями сохраняет манифест и удаляемые файлы в
`/tmp/tts-sync-<дата>-<время>/`.

## Старый скрипт

`sync_routes.py` умеет только `navigator3` (YDB) и не чистит лишнее. Оставлен
для совместимости; для полной синхронизации используйте `sync_all.py`.
