# navigatortg2 — навигатор и редактор

Отдельный проект, вынесенный из `navigatortg/`. Здесь тестовые версии
навигатора и редактора на MapLibre; в `navigatortg/` — рабочая версия на
Яндекс.Картах.

## Страницы

- `navigator.html` — навигатор onepage2 на MapLibre + PMTiles.
- `editor.html` — редактор маршрутов и знаков: интерфейс перенесён из
  `navigator3` (вкладки «Маршруты», «Знаки», «Инструкция», «Настройки»,
  дерево папок, перетаскивание маршрутов, настройки карты и темы). Вход —
  только по подписи Telegram.
- `index.html` — редирект на `navigator.html`.
- `instr.html`, `instr_editor.html` — инструкции, подгружаются через `fetch`.
- `assets/` — стили и скрипты проекта. `config.js`, `tts-client.js`,
  `report.js`, `editor.css` скопированы из `navigatortg/`; остальные файлы
  относятся к версии на MapLibre. Правки здесь не влияют на `navigatortg/`.

API общий — воркер `nav-api-v2` (`https://nav-api-v2.ivan43103.workers.dev`),
данные в D1 `nav-db-v2`. Воркер и база свои, независимые от `navigatortg/`:
исходники воркера лежат в `navigatortg2/cloudflare_worker/` (`api.js`, `lib/`,
`schema.sql`, `wrangler-api.toml`), данные перенесены из `nav-db` копией таблиц
`folders`, `roads`, `purchases`. Таблицы инструкторов удалены — функционал
больше не используется.

### Воркер и база

```bash
cd navigatortg2/cloudflare_worker
npx wrangler d1 execute nav-db-v2 --remote --file=schema.sql --config=wrangler-api.toml
npx wrangler deploy --config=wrangler-api.toml
```

Секреты воркера:

- `TELEGRAM_TOKEN` — нужен для входа в редактор по подписи Telegram, отчётов и
  оплаты звёздами. Задаётся вручную: `npx wrangler secret put TELEGRAM_TOKEN
  --config=wrangler-api.toml`;
- `TG_SECRET` — секрет вебхука Telegram. У одного бота может быть только один
  вебхук, поэтому тестовый воркер не должен его перехватывать; для независимой
  проверки оплат нужен отдельный тестовый бот.

## Владение маршрутами

Маршруты и папки привязаны к Telegram-аккаунту: в таблицах `roads` и `folders`
есть колонка `owner_tg_id`. В редакторе пользователь видит и меняет только свои
маршруты и папки; публичный каталог по-прежнему показывает все видимые
маршруты. Владелец открывает свои маршруты без покупки, даже если папка платная.
Платные папки в навигаторе выделены: в списке — золотая рамка, а под
названием — «★ Премиум N»; длинные названия переносятся на несколько строк.
В хлебных крошках у платной папки звёздочка.

- Вход в редактор — только `Telegram.WebApp.initData` (подпись проверяется
  токеном бота). Подходит любой пользователь Telegram, списков доступа и
  ключей нет. Вне Telegram редактор показывает сообщение, что доступен только
  в Telegram.
- Новые маршруты и папки получают `owner_tg_id` текущего пользователя.
- Миграция: `cloudflare_worker/migrations/2026-11-19-route-ownership.sql`
  добавляет колонки и закрепляет существующие данные за `7292595756`.

## Редактор

Редактор повторяет интерфейс `navigator3`, но работает с Telegram-аккаунтом и
воркером `nav-api-v2`:

- все данные — только текущего владельца (`owner_tg_id`);
- вкладка «Маршруты»: дерево папок, создание/переименование/удаление,
  перетаскивание маршрутов между папками, настройки маршрута;
- в настройках папки дополнительно есть цена доступа в звёздах и видимость
  (модель платных папок `navigatortg2`);
- у владельца есть одна корневая папка (таблица `owner_roots`), её название
  задаётся в «Настройках» → «Корневая папка». Новые папки и маршруты,
  созданные «в корне», попадают внутрь неё и видны в навигаторе;
- в навигаторе под названием корневой папки показывается кликабельный бейдж
  владельца; по нажатию открывается окно с аватаром, именем, @username, информацией,
  кнопкой «Связаться с автором» и корневой папкой. Имя владельца хранится в `owner_roots.owner_name` (по
  умолчанию — Telegram ID), информация — в `owner_info`, аватар и username — из
  Telegram при открытии редактора;
- вкладка «Знаки»: каталог, установка, поворот, таблички, ножка, сохранение;
- вкладка «Инструкция» и «Настройки» (слой карты, тема);
- вкладка «Профиль»: Telegram-профиль, поле «Информация» (по умолчанию
  @username, можно изменить) и название корневой папки.

Флаг «Премиум» отдельного маршрута из `navigator3` не используется: в
`navigatortg2` премиум определяется ценой папки.

## Дорожные знаки

- `signs/catalog.json` и `signs/webp/` — каталог и картинки знаков (скопированы из `pad/znaki/`).
- В редакторе вкладка **«Знаки»**: знак ставится в центр карты, его можно двигать,
  поворачивать, добавлять таблички и ножку. Сохранение — «Сохранить знаки».
- Сцена одна на Telegram-аккаунт: таблица `owner_signs` (`owner_tg_id`, `data`,
  `updated_at`), API-экшены `signs_get` / `signs_save`.
- Навигатор получает знаки владельца вместе с пакетом корневой папки
  (`owner_bundle`) и рисует их слоем MapLibre. Показ можно выключить в
  настройках («Знаки»).
- Миграция: `cloudflare_worker/migrations/2026-11-19-owner-signs.sql`.

## Деплой

```bash
./navigatortg2/deploy-v2.sh
```

Скрипт публикует проект Cloudflare Pages `avtoinstruktor-v2` (новый домен
`https://avtoinstruktor-v2.pages.dev`), собирает staging по белому списку,
подставляет `?v=<build>` в ссылки на статику и пишет `version.json` (его
использует автообновление мини-аппа). Имя проекта можно переопределить:

```bash
PROJECT_NAME=my-test ./navigatortg2/deploy-v2.sh
```

## Проверка

Страницы рассчитаны на Telegram WebView, но открываются и в браузере. Если
нужен локальный сервер:

```bash
python3 -m http.server 8080 --directory navigatortg2
```
